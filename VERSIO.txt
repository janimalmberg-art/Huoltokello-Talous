================================================================
HUOLTOKELLO-TALOUS - muutoshistoria
================================================================

Sovellus: pienyrityksen talous- ja laskutusmoduuli Huoltokello-tyon-
hallinnan rinnalle. Asennuspaketti: Huoltokello-Talous-<versio>.zip.

v1.4.0-kokeilu - 27.11.2026
---------------------------
- UUSI: Lisenssijarjestelma (huoltokello_talous/licenssi.py). Ilman lisen-
  ssia ohjelma toimii 90 paivan kokeilujaksolla kuten aiemmin; voimassa
  oleva lisenssi ohittaa kokeilurajoitukset. Tuetut tasot: 01 Yritys Pieni
  (1 serveri / 50 tyontekijaa / johto +5), 02 Yritys (1/300/+10),
  03 Yritys Suuri (1/900/+20) ja 04 Yritys Enterprise (5/2000/+100).
- Lisenssiavain 25 numeroa (XXXXX-XXXXX-XXXXX-XXXXX-XXXXX) + kehittajan
  konekohtainen aktivointikoodi 12 numeroa (XXXXXX-XXXXXX). Aktivointi
  sidotaan konekoodiin (MachineGuid + C-aseman sarjanumero + koneen
  nimi, HMAC): sama avain ei kelpaa toiselle koneelle ilman uutta koodia
  (kehittaja myontaa koodit Lisenssityokalulla ja vapaauttaa sidonnat
  uudelleenasennuksissa). Paivitys isompaan tasoon: uusi avain, data
  sailytetaan.
- Kokeilujakson paattymisikkunaan (ruudun keskelle) lisatty
  "Lisenssiavain"/"Aktivointikoodi" -kentat ja AKTIVOI-painike: aktivoinnin
  jalkeen ohjelma kaynnistyy uudelleenajossa normaalisti (poistumiskoodi 2
  vain jos lisenssia ei anneta). Konekoodi naytetaan samassa ikkunassa.
- UUSI komento: python -m huoltokello_talous lisenssi [tila | aktivoi
  --avain X --koodi Y]. Tila tulostaa konekoodin ja lisenssin tiedot.
- UUSI web-sivu: Hallinta > Lisenssi (/lisenssi, johto): nykytilan tiedot,
  konekoodi ja aktivointilomake. Ajossa oleva palvelinvalvonta ei pysayta
  palvelinta, kun voimassa oleva lisenssi on tallennettu.
- Lisenssitila talteen kaikille ohjelmille yhteiseen tiedostoon
  %APPDATA%\Hk-Lisenssi\lisenssi.json (varmiste HMAC-SHA256; kasimuokkaus
  havaitaan). Sama avain aktivoi molemmat ohjelmat samassa koneessa.
- Asennusvelho kysyy valinnaisen lisenssiavaimen ja aktivointikoodin
  asennuksen lopussa (jattamalla tyhjiksi jatkuu 90 pv kokeilulla).
- Testit: tests/test_licenssi.py (kultavektorit kehittajan Lisenssi-
  tyokalusta; PowerShell-_lisensi.ps1 tuottaa samat tulokset).

v1.3.1-kokeilu - 27.11.2026
---------------------------
- KOKEILUVERSIO (rajoitettu julkaisu GitHubissa): ohjelma toimii 90
  paivaa ensimmaisesta kaynnistyksesta (huoltokello_talous/trial.py).
  Alkupaiva kirjataan datakansioon (kokeilu.json, varmistekentta);

  kaynnistys estetaan ja naytetaan ruudun keskella ikkuna:
  "Kokeilujaksosi on paattynyt" + kehittaja Jani Malmberg (ohjelman
  kehittaja), s-posti jani.malmberg@gmail.com + tieto, etta tayden
  version ja lisenssien voi pyytaa kehittajalta s-postitse. Poistumis-
  koodi kaynnistysta estettaessa: 2.
- Ajossa oleva palvelinvalvonta: taustasaeie tarkistaa kokeilujakson
  tunnin valelein ja pysayttaa palvelimen jaksontaytyessa.
- Testit: tests/test_kokeilu.py (8 uutta testia).
- Graafiset kokeiluikkunat voi ohittaa testiajoissa ymparistomuuttujal-
  la HKT_KOKEILU_EI_IKKUNAA=1.

v1.3.0 - 25.11.2026
-------------------
- UUSI komento: python -m huoltokello_talous demodata. Lataa tyhjaan
  tietokantaan valmiin esittelyaineiston (huoltokello_talous/demo.py):
  demoyrityksen, tyolajit, asiakkaat (Y-tunnukset ja OVT-tunnukset
  generoiduina), tarvikkeet, asiakashinnat, tyontekijat, kayttajat
  kaikille rooleille, kaksi kuukautta tyoaika- ja tarvikekirjauksia
  (hyvaksytty/lahetetty/luonnos/hylatty), kaksi tarjousta, laskuja
  kaikissa tiloissa (maksettu, osamaksu, eraantynyt + maksumuistutus
  viivastyskoroilla, hyvitetty + hyvityslasku, luonnos + kasin lisatty
  rivi) sek lukitun ja luonnoksellisen palkkajakson jaksotusviennit
  (PA). Aineisto luodaan moduulien julkisilla funktioilla, jolloin
  laskunumerointi, ALV-koodit (ALV25.5, RAK, EIALV), RF-viitteet ja
  tilioinnit noudattavat tuotantologiikkaa. Lataus vain tyhjaan
  tietokantaan ja vain kerran (asetus demo.seeded, suojattu
  _assert_empty()-tarkistuksella, tarkastusketjuryys kirjataan).

v1.1.0 - 19.11.2026
-------------------
- UUSI: Huoltokello-silta (huoltokello_talous/hk_bridge.py + tests/
  test_hk_bridge.py). Talous lukee Huoltokellon SQLite-tietokantaa
  suoraan, vain lukuna - ei koskaan kirjoita Huoltokellon tietoihin:
    * asiakkaat (Customers)        -> asiakkaat, numerolla HK<id>
    * kauttajat (AspNetUsers)      -> tyontekijat, tasmays s-postilla
    * tehtavakategoriat            -> tyolajit, tasmays nimella
    * kuittaukset (HoursWorked)    -> tyoaikakirjaukset tilaan
      'lahetetty' (vaativat hyvaksynnan), task_ref HK-<tehtava>
    * kuittausten tarvikkeet        -> tarvikekirjaukset
- Siltamuuttuja tallennetaan nyt tietokantaan (taulu settings, avain
  hk.db_path). Talouksen rakennepaivitys kasvoi 1 -> 2 (user_version),
  migraatio ajetaan alustuksessa automaattisesti.
- UUSI komento: python -m huoltokello_talous huoltokello-synk
  [--esikatselu] [--polku X]. Esikatselu nayttaa tuotavaa ennen ajoa;
  jo tuotuja, paallekkaisia tai lukittujen palkkakausien kirjauksia ei
  tuoda uudelleen (idempotentti).
- UUSI web-sivu: Rekisterit > Huoltokello-yhteys (siltapolumappi,
  huoltokellon kannan sijainti, esikatselu ja valinnainen automaattinen
  synkronointi).
- Kellonia (loppu = kuittausaika, alku = loppu - tunnit; saman paivan
  kuittaukset ketjutetaan perakkain). Kirjausta ei laskuteta, jos
  tehtava on laskutettu Huoltokellossa tai asiakkaalla on kuukausi-
  hintainen sopimus ilman tuntihintaa.
- Huoltokello-Multiasennus-velho (v2.8.0) tukee talousmoduulin asennusta
  rinnalle (valintaruutu chkTalous / -AsennaTalous-lippu): purkusijainti
  %LOCALAPPDATA%\Huoltokello-Talous, siltasidonta, kaynnistin ja
  pikakuvakkeet.
- README: uusi osiot Huoltokello-sillasta.
